Installation guides

Separate setup instructions for Android and Windows.

Android APK installation

For Android phones and tablets.

  1. Tap Download Android APK.
  2. Wait for the download and open the APK from Downloads.
  3. If Android asks, open Settings and permit Install unknown apps for your browser or Files app.
  4. Return to the APK and tap Install, then Open.
  5. You can turn off the install permission afterward.

Only install downloads you trust. To update over an existing installation, Android may require the same signing certificate.

↓ Download Android APK

Windows installation

For Windows desktop and laptop PCs.

  1. Tap Download Windows app.
  2. Open the downloaded FlixLeo setup EXE.
  3. Review its publisher and source. Windows SmartScreen may warn about unsigned installers.
  4. Proceed only if you trust the file, then follow the setup prompts.
  5. Launch FlixLeo from your desktop or Start menu shortcut.

Never bypass an unexpected security warning for a file you cannot verify. You can always use FlixLeo in a browser instead.
